## Главный принцип

```
Центральный склад → Магазины → Продавцы → Продажи → Аналитика
```

Магазин **не** создаёт товары. Источник — только склад.

Модель остатков (уже в Prisma):

```
Product → Batch → StockBalance(locationType + locationId)
                  WAREHOUSE | STORE
```

Отдельная таблица `Location` не обязательна: `locationId` = `Warehouse.id` или `Store.id`.

## Ручные / архитектурные правки

1. **Enum / статус из API** — UI переводит ключи (`active`, `PENDING`, `ACTIVE`), не сырой русский.
2. **Типы товаров** — `labelProductType()` мапит канонические RU-имена из БД → i18n.
3. **Ошибки API** — `handleApiError` не отдаёт Prisma; коды → `errors.*` (доработка API-маршрутов — в том же цикле).
4. **Переключатель языка** — клиентский `I18nProvider` + cookie/localStorage; страницы на `t()` обновляются без reload.

## Как проверить

1. Войти как owner → переключатель RU ↔ TJ на каждой странице меню.
2. Seller POS → те же проверки.
3. Создать товар / бренд / партию — сообщения об ошибках на языке UI.
4. `npx tsc --noEmit`

## 6. Почему «отправил — в магазине не видно» (разбор причины)

### Историческая причина (до fix data-flow)

1. Seed кладёт **весь** товар на `WAREHOUSE`, магазин пуст.  
2. Transfer сервис уже писал `STORE` stock — но **POS не читал** store stock.  
3. **Sale API не было** — цепочка обрывалась визуально на продавце.  
4. Владелец смотрел UI без проверки `StockBalance` магазина.

### Сейчас (проверка БД)

После transfer в БД у Магазин №1 / №2 **есть** остатки.  
`npm run test:stock-flow`: 100 → 20 → 80/20 → sale 5 → 80/15 — **PASS**.

Если в UI «пусто»:

1. Не выполнен transfer (или в другой филиал).  
2. Seller привязан к другому `storeId`.  
3. Смотрят Owner Direct / склад вместо вкладки «Остатки» филиала.  
4. Старая вкладка браузера до деплоя POS catalog.

Команда: `npx tsx scripts/diagnose-stock.ts`

## 9. Database

Связи достаточны:

```
Company → Warehouse, Store, Product, User
Product → Batch, StockBalance, SaleItem
Transfer → TransferItem → Batch (source) + new STORE Batch
Sale → SaleItem → Batch (FIFO cost)
ActivityLog (append-only)
```

Миграции: есть; часть эволюции через `db push` — перед production нужен чистый migrate history.

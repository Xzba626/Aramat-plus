# Правила партий товара

## Основной принцип

Партии **не объединяются**. Каждая партия — отдельная запись с собственной себестоимостью и датой прихода.

Пример:
- Партия №1: 100 мл, себестоимость 100 сомони, дата 2026-01-01
- Партия №2: 150 мл, себестоимость 120 сомони, дата 2026-01-08

## Цена продажи

- `Product.salePrice` — текущая цена продажи
- Изменение salePrice влияет только на **новые** продажи
- История цен хранится в `PriceHistory`
- Прошлые продажи хранят snapshot цены в `SaleItem.salePrice`

## Списание (FIFO)

При продаже или перемещении товар списывается из партий по принципу **FIFO** (First In, First Out):
1. Сортировка партий по `receivedAt ASC`
2. Списание из старейшей партии с ненулевым остатком
3. Если партия исчерпана — переход к следующей

## Перемещение склад → магазин

1. Списание из партий склада (FIFO)
2. Создание новых партий в магазине с **сохранением** себестоимости исходных партий
3. Запись `Transfer` + `TransferItem` с привязкой к batchId
4. ActivityLog

## Типы учёта

- `WEIGHT` — на разлив (граммы/мл), дробные количества
- `PIECE` — поштучно, целые числа

## Отличие от mockup

HTML mockup использует средневзвешенную себестоимость — **не применяется** в production-системе.

# Owner Dashboard Specification — Document №13.1

**Проект:** AROMAT PLUS ERP  
**Раздел:** Главная (Dashboard владельца)  
**Версия:** 1.0  
**Связанные документы:** [UI Blueprint №13](ui-blueprint.md) · [IA №15](ia-three-centers.md) · [UI Design System №4](ui-design-system.md)

> Главная — **центр контроля сети**, не рабочее место операций.  
> За 5–10 секунд владелец понимает: что сегодня, где проблемы, где хорошо, что решить сейчас.

---

## 1. Назначение

После входа владелец видит:

- что происходит сегодня;
- есть ли проблемы;
- какие магазины работают хорошо / требуют внимания;
- какие действия нужны **прямо сейчас**.

Только важная информация + быстрый переход в разделы.

---

## 2. Запрещено на главной

Нельзя: создавать/редактировать товар, продажи, возвраты (полный flow), ревизию, менять остатки.

Для этого — соответствующие разделы.  
Исключение: **инлайн Одобрить / Отклонить** в блоке «Требуют моего решения».

---

## 3. Header (закреплён)

| Зона | Содержание |
|------|------------|
| Слева | Логотип + название компании («AROMAT PLUS» / Company · ERP System) — на desktop дублирует бренд в top bar; на mobile — рядом с ☰ |
| Центр | Дата и время, **обновление каждую секунду** |
| Справа | Уведомления · Профиль · Выход |

---

## 4. Четыре вопроса Dashboard

1. Что происходит сегодня?  
2. Есть ли проблемы?  
3. Где требуется внимание?  
4. Что изменилось после последнего входа? *(лента действий)*  

Плюс: **что требует моего решения?** (блок №7).

---

## 5. Блок «Сегодня»

Данные с **00:00 текущих суток до текущего момента** (не «полный день»).

| Показатель |
|------------|
| Продажи сегодня (сомони) |
| Чистая прибыль сегодня |
| Количество продаж |
| Продано товаров (сумма qty) |
| Средний чек |

Под каждым: Δ к **аналогичному интервалу вчера** (00:00 → то же время суток вчера): `↑ +12%` / `↓ -7%`.

---

## 6. Блок «Важные уведомления»

Только требующие внимания (low stock, скидка, возврат, ревизия…).  
Макс. **5** + кнопка «Показать все» → `/notifications`.

---

## 7. Блок «Магазины сегодня»

Кратко по каждому магазину: продажи · прибыль.  
Клик → `/stores/[id]`.

---

## 8. Блок «Товары, требующие внимания»

Скоро закончатся / нет в наличии (красная подсветка).  
Единицы: шт или мл по типу товара.

---

## 9. Блок «Последние действия»

Последние **10** событий audit.  
Кнопка → `/journal`.

---

## 10. Блок «Быстрые переходы»

Ссылки (не операции): Склад · Магазины · Возвраты · Аналитика · Пользователи · Настройки.

---

## 11. Блок №7 — «Требуют моего решения» ★ главный

Только задачи, которые **не завершить без Owner**.

| Тип | Действия на карточке |
|-----|----------------------|
| Скидка | магазин, продавец, товар/сумма, цены, % · Одобрить / Отклонить |
| Возврат | товар, причина, чек, qty · Одобрить / Отклонить |
| Изменение цены | текущая → новая, причина, менеджер · Одобрить / Отклонить |
| Списание | товар, qty, причина, фото · Одобрить / Отклонить |
| Новая партия (опц.) | если включено в настройках |

**Счётчик:** `Требуют моего решения (N)` + разбивка по типам.  
Если N = 0: свёрнуто — «Все задачи обработаны. Новых запросов нет.»

**Приоритет сортировки:** просроченные → срочные → новые → остальные.

**Цвета:** 🔴 немедленно · 🟠 сегодня · 🟢 инфо (без перегруза).

Каждое решение → immutable audit (в архив только по правилам хранения).

---

## 12. Автообновление

| Данные | Интервал |
|--------|----------|
| Время в header | 1 с |
| Уведомления / решения | 10 с |
| Статистика (Сегодня, магазины, товары) | 30 с |

Без кнопки «Обновить».

---

## 13. Desktop layout

```
Sidebar | Header
        | Сегодня
        | Требуют моего решения
        | Уведомления          | Магазины сегодня
        | Товары внимания      | Последние действия
        | Быстрые переходы
```

---

## 14. Mobile layout

Одна колонка: Header → Сегодня → Решения → Уведомления → Магазины → Товары → Действия → Переходы.  
☰ открывает sidebar.  
**Нижний tab bar Owner не используется** (слишком много модулей).

---

## 15. RBAC

Owner — всё. Manager — по permissions. Seller — **не видит** Dashboard (сразу POS).

---

## 16. Принципы UI

Минимум шума · читаемость · единые отступы/карточки · бренд DS №4 · auto-refresh · ≤2 клика до раздела.

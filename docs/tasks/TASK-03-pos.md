# DEVELOPMENT TASK №3 — SELLER POS (MOBILE)

**Статус:** Обязательное ТЗ · реализация после TASK 04 (Магазины) или параллельно по согласованию  
**Проект:** AROMAT PLUS ERP  
**Поверхность:** отдельное приложение внутри ERP · телефон / планшет first

> Это **не** увеличенный Desktop Owner.  
> POS **не** использует Owner Dashboard, склад, аналитику, журналы.  
> Цель: **продажа за 10–15 секунд**. Всё, что не относится к продаже — скрыто.

---

## Главный принцип

Задача продавца:

> Найти товар → корзина → оплата → чек.

Не аналитика. Не склад. Не управление сетью.

---

## Запрещено в POS

- Owner sidebar / Desktop layout  
- Dashboard, графики, KPI-карточки  
- Склад, партии, себестоимость, прибыль  
- Журнал действий всей компании  
- Управление пользователями / настройками сети  

---

## Маршруты

| Экран | URL |
|-------|-----|
| Продажа (главный) | `/pos` |
| История | `/pos/history` |
| Корзина | `/pos/cart` |
| Уведомления | `/pos/notifications` |
| Профиль | `/pos/profile` |

После логина `SELLER` → сразу `/pos` (экран продажи). Без промежуточного dashboard.

---

## 1. Верхняя панель

- логотип  
- название **магазина** продавца  
- имя продавца  
- дата · время  
- онлайн / офлайн  
- справа: уведомления  

---

## 2. Поиск

Большое поле. Одновременно: название · бренд · артикул · QR · штрихкод.  
Скан → товар **сразу в корзину** (без лишних экранов).

---

## 3. Быстрые категории

Под поиском (из категорий компании / магазина). Тап → фильтр каталога.

---

## 4. Каталог

Карточка: фото · название · объём · цена · остаток.  

Метки:

- жёлтая — заканчивается  
- красная — нет в наличии  
- зелёная — акция / подарок  

Тап по карточке → **сразу в корзину** (без отдельной страницы товара).

---

## 5. Нижняя навигация (только 5)

```
Продажа · История · Корзина · Уведомления · Профиль
```

---

## Корзина

Товары · qty · цена · скидка · подарок · итог.  

Кнопки: **Отмена** · **Продать**.  

Скидка без прав → запрос Owner. Без скидки → продажа сразу. FIFO со склада магазина.

---

## История

Только продажи **этого** продавца. Время · чек · сумма · qty · статус. Открыть / перепечатать. Удаление запрещено.

---

## Уведомления

Только свои: скидка approved/rejected · возврат · акция · сообщение Owner.

---

## Профиль

Имя · магазин · должность · смена пароля · выход. Роль не редактируется.

---

## Производительность (обязательно)

- продажа ≤ 10–15 с  
- действие ≤ 2–3 тапа  
- скан → мгновенно в корзину  
- мгновенный visual feedback  
- отзывчивость при большом каталоге  

---

## Связь с данными

Остатки магазина — только из складских движений (TASK 02).  
Продажа списывает FIFO на `LocationType.STORE` (филиал).  
Owner Direct POS — отдельный канал (№17), не Seller POS.

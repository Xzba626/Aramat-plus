# DEVELOPMENT TASK №4 — МАГАЗИНЫ (Owner Desktop)

**Статус:** Обязательно к реализации · **текущий этап**  
**Проект:** AROMAT PLUS ERP  
**Порядок:** после TASK 01–02 · перед live POS (TASK 03)  

> Центральный экран управления сетью торговых точек.  
> Данные остатков — только из склада (TASK 02).  
> Не путать с Seller POS (TASK 03).  
> Канон логики: [Документ №15](../stores-module.md) · [Owner Direct №17](../owner-direct-sales.md).

---

## Важно

Это не предложение. Обязательные требования.

- Не упрощать вкладки и KPI.  
- Не вводить ручной ввод остатков.  
- Не удалять магазин — только архив.  
- Не смешивать Owner Desktop с Seller POS.  
- UI-название раздела: **«Магазины»**.

---

## Назначение

Владелец управляет всеми точками:

- филиалы (`BRANCH`);  
- канал личных продаж (`OWNER_DIRECT`) — первый в списке.

Каждая точка: свои остатки (или склад для Owner Direct), сотрудники, история, запросы, аналитика точки.

---

## Список `/stores`

Карточка филиала (обязательные поля):

название · статус (Работает / Закрыт / На ревизии) · адрес · сотрудники · SKU · единицы · стоимость остатка · продажи сегодня · продажи месяц · прибыль · ожидающие запросы · последняя продажа · последняя ревизия.

Одно нажатие → карточка точки.

Сводка сети сверху: число филиалов · суммарные продажи сегодня · суммарные pending-запросы.

---

## Вкладки филиала

```
Обзор · Остатки · Продавцы · История продаж · История скидок
· История возвратов · История ревизий · Запросы · Настройки
```

Owner Direct: без «Продавцов» и «Ревизий филиала»; + «Остатки склада» + кнопка продаж канала.

---

## Инварианты

1. Остаток = движения склада (приход / продажа / возврат / списание / transfer).  
2. Transfer только в BRANCH.  
3. Blind revision для Manager.  
4. Пароль продавца — только hash.  
5. Полный audit log.

---

## RBAC

| Роль | Магазины |
|------|----------|
| Owner | полный доступ + финансы |
| Manager | точки по назначению; без полной фин. аналитики сети |
| Seller | нет Owner `/stores` → только POS |

---

## Требование к UI

Desktop Owner: sidebar «Магазины» · широкий workspace · правая панель по необходимости.  
Минимум кликов. Единые карточки / таблицы TASK 01.

После модуля — можно углублять live POS (TASK 03).

> Это не предложение и не пример. Это обязательные требования.

---

## Главная цель

Профессиональная Desktop ERP для ежедневной работы владельца сети магазинов.

Приоритеты: скорость · минимум кликов · логичная структура · единый стиль · масштабирование без переделки.

## Layout

Три зоны: **Sidebar** (навигация) · **Workspace** (контент) · **Right panel** (только по необходимости, иначе скрыта).

## Sidebar

- Фон: `#1E293B` (не чёрный)
- Бренд: `#C62839`
- Рабочая область: `#F6F8FB`
- Карточки: `#FFFFFF`, границы: `#E5E7EB`

Логотип компактный → **AROMAT PLUS ERP** → подпись *Commercial Management System*

## Меню (короткое, древовидное)

Главная · Склад* · Магазины · Возвраты · Ревизия · Аналитика · Пользователи · История · Уведомления · Настройки

\*Склад раскрывается: Товары · Категории · Партии · Остатки · Перемещения · История склада

Только **один** активный раздел раскрыт.

## Top bar

Слева: название раздела. Справа: поиск · уведомления · пользователь · аватар · меню профиля.

## Splash

~3 с: логотип · название · «Добро пожаловать» → авторизован → workspace; иначе → login.

## Роли

Owner/Manager → Desktop · Seller → POS

## Компоненты

Единые карточки · кнопки (primary/secondary/danger/ghost) · таблицы · формы · breadcrumbs.

Desktop-first; mobile — позже как адаптация, не отдельный UI.

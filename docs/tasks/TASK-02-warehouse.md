# DEVELOPMENT TASK №2 — WAREHOUSE MODULE (CORE)

**Статус:** Обязательно к реализации  
**Проект:** AROMAT PLUS ERP  
**Порядок:** после TASK 01 (Desktop UI) · до Stores / POS / Analytics

> Склад — **единственный источник данных** для всех модулей.  
> Никакой товар не появляется в магазине без склада.  
> Не разрабатывать другие разделы, пока склад не рабочий.

---

## Главный принцип

Один **Центральный склад** → единственный источник товаров.  
Создание товара только на складе → затем перемещение в магазин.

## Навигация

В главном меню — **только «Склад»**.

## Обзор

KPI: стоимость склада · себестоимость · SKU · единицы · партии · низкий остаток · последние поступления / перемещения / возвраты.

## Каталог

Фото · название · артикул · штрихкод · категория · бренд · ед. · тип · цена · остаток · статус.  
CRUD + **архив** (удаление запрещено).

## Партии

Каждое поступление = новая партия. **Никогда не объединять.** FIFO. История неизменяема.

## Приход

Два сценария в UI: **новый товар** | **новая партия** существующего.

## Перемещение

Склад → Магазин → qty → подтверждение. FIFO. Audit log.

## Возврат

Магазин → Склад. Причина · пользователь · время · история.

## Остатки

По товару: общий · по партиям · по магазинам · на центральном складе.

## История

Автозапись: дата · время · пользователь · роль · действие · объект · qty · комментарий · IP. Не редактируется.

## RBAC

| Роль | Склад |
|------|-------|
| Owner | полный доступ + финансы |
| Manager | склад без финансовой аналитики |
| Seller | нет доступа |

# ТЗ: Номенклатура vs склад — создание товара

**Проект:** AROMAT PLUS ERP  
**Версия:** 1.0 · 2026-07-30  
**Принцип:** сначала карточка товара (номенклатура), потом движение остатков (склад).

> Не смешивать в одной форме: создание товара, первичный остаток, приход партии, продажу и аналитику.

---

## Разделение процессов

| # | Процесс | Где | Что делает |
|---|---------|-----|------------|
| 1 | Создание карточки | `Склад → Товары → Создать` | Только номенклатура |
| 2 | Первичный остаток (запуск) | Карточка → «+ Добавить остаток» | Кол-во уже физического товара |
| 3 | Новая партия (будущее) | `Склад → Приём` или карточка → «+ Новая партия» | FIFO-партия + с/с |
| 4 | Продажа | POS | шт / мл (+ флакон — позже) |
| 5 | Аналитика | Аналитика | по типу, бренду, товару |

---

## Форма «Создание товара» — оставить

| Поле | Правило |
|------|---------|
| Название | обязательно |
| SKU | авто `ARM-XXX-0001`, можно оставить как есть |
| Фото | UI-плейсхолдер (загрузка — этап 2) |
| Описание | необязательно |
| Бренд | выбор / «+ новый бренд» |
| **Тип товара** | для аналитики (не «категория»): Парфюм, Масляные духи, Дезодорант, Освежитель, Часы, Аксессуары, Другое |
| **Как продаём** | Штучный (`PIECE`) / По объёму мл (`WEIGHT`) — единица склада |
| Себестоимость (план) | `defaultCostPerUnit` — справочная; реальная с/с на партии |
| Цена продажи | `salePrice` |

Единица (`unitId`) подставляется автоматически: мл или шт.

---

## Форма — убрать

- ❌ Категория (оставить в БД для совместимости, не показывать в create)
- ❌ Первая партия / количество партии
- ❌ Минимальный остаток (настройка склада — отдельно, позже)

---

## После сохранения

Редирект на карточку товара:

```
Название · SKU · Бренд · Тип · Продажа · С/с · Остаток: 0
Кнопки: + Добавить остаток | + Новая партия | Редактировать
```

---

## Партии и остатки

- **Добавить остаток** = та же операция `addBatch` (первичный запуск).
- **Новая партия** = тот же `addBatch` с возможностью новой с/с и цены.
- Партии **не объединяются** (см. [batch-rules](batch-rules.md)).

---

## Флаконы (обязательная модель)

**Не товар.** См. [packaging-bottle-model.md](packaging-bottle-model.md).

- `PackagingMaterial` — отдельный склад, FIFO, без POS и выручки.
- COGS = жидкость + флакон; не Expense.
- Запрещены SKU `Dior 5ml` / `Dior 10ml` как `Product`.

## QR (этап 3+)

После стабильных склад / партии / продажи / прибыль.

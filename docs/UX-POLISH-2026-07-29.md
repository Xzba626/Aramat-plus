2. **Топбар единый** — логотип, название раздела, глобальный поиск → каталог, дата/время, уведомления, профиль  
3. **Сайдбар** — графитовый `#243044`, красный только акцент

7. **Аналитика** — вкладки через `?view=` синхронизированы с меню  

## Сценарии (пройти вручную перед Backend)

### Владелец
1. Главная → видит KPI и «Требуют решения»  
2. Склад → Каталог → создать товар / найти через поиск в топбаре  
3. Поступления → новая партия  
4. Отправки → в филиал  
5. Магазины → Все / Личные продажи → POS владельца  
6. Возвраты → одобрить/отклонить  
7. Ревизии → вид владельца (должно / факт / разница)  
8. Аналитика → сеть / товары / продавцы / финансы  
9. Система → пользователи / журнал / настройки  

### Менеджер
1. Склад: поступление, отправка, возврат на склад, списание (UI)  
2. Ревизия: создать → ввести факт (без «должно быть»)  
3. Не видит пункты Пользователи (если роль Manager)  

### Продавец
1. `/pos` → поиск → корзина → продажа  
2. История продаж  
3. Уведомления (экран готов)  

## Критерий готовности к Backend

Если на любом шаге сценария пользователь **задумывается, где кнопка** — доработать UI ещё раз.  
Только после уверенного прохождения трёх ролей — разрешать серверную логику.

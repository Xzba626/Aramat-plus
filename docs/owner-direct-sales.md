## 1. Решение

Владелец **не** оформляется как обычный филиал.

Это отдельный **тип торговой точки**:

**«Личные продажи владельца»** (`StoreKind.OWNER_DIRECT`)

Универсальное имя: Instagram / Telegram / WhatsApp / личные продажи — один канал.

Раздел UI переименовывается: **«Торговые точки»** (не «Магазины»).

---

## 2. Почему не обычный магазин

| Обычный филиал | Owner Direct |
|----------------|--------------|
| Склад → Магазин → Продажа | **Склад → Продажа** |
| Нужно перемещение | Перемещения **нет** |
| Остатки на точке | Остатки = центральный склад |
| Seller POS | Owner POS с расширенными правами |

---

## 3. Правила сущности

- создаётся **автоматически** при создании компании;
- **ровно один** `OWNER_DIRECT` на `companyId`;
- нельзя удалить / архивировать как обычный филиал (только деактивировать канал в настройках — v2);
- нельзя назначить продавца «привязанным только сюда» как к филиалу (продавцы работают в BRANCH);
- нельзя выбрать как назначение `Transfer` (отправка только в BRANCH).

---

## 4. UI списка «Торговые точки»

Первая карточка всегда:

```
⭐ Личные продажи владельца
Источник: Центральный склад
Продажи сегодня / Выручка
Остатки: напрямую со склада
```

Ниже — филиалы (`BRANCH`).

---

## 5. Внутри канала

Интерфейс как у продавца: поиск · каталог · корзина · продажа · история.

Источник qty: **warehouse stock**.  
Скидка: Owner применяет сам (в истории фиксируется).  
Возврат: сразу на центральный склад.

Вкладки workspace: Продажи · История · Остатки (склад) · Возвраты · Аналитика канала · (без «сотрудников филиала»).

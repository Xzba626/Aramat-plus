## Что сделано в этом проходе

### 1. Серверные ошибки → коды + i18n
- `handleApiError` больше **не отдаёт** сырой текст (Zod EN, Prisma, русские throw).
- Все известные коды в whitelist; остальное → `INTERNAL_ERROR`.
- Сервисы (`stock`, `sale`, `transfer`, `warehouse-return`, `stores-detail`, `pos-catalog`) переведены с русских `throw new Error("…")` на коды (`INSUFFICIENT_STOCK`, `EMPTY_CART`, …).
- `rbac` / `middleware`: `UNAUTHORIZED` / `FORBIDDEN` вместо English.

### 2. Enum / статусы в UI
- Добавлены `labelSaleStatus`, `labelDecisionStatus`, `labelRevisionStatus`.
- Исправлены: карточка магазина (роль, продажи, скидки, возвраты, ревизии, запросы), POS history.
- Расширены `ACTION_KEYS` / `ENTITY_KEYS` (write-off, expense, brand, category…).

### 3. Уведомления
- Сервисы скидок/возвратов пишут **ключи** (`notif.discountRequest`, …) в `title`.
- API notifications определяет ключ и отдаёт `titleKey`.
- Owner notifications UI переводит через `resolveNotifTitle`.

### 4. UI-мелочи
- Splash: убран English tagline → `splash.tagline`.
- Placeholders справочников, mock POS notifications, units fallback, writeOffsHint key.
- Products API: убран русский `statusLabel` (остался `statusKey`).
- Ошибки на страницах stores/users/settings/warehouse идут через `apiErrorMessage`.

### 5. Переключатель языка
- Клиентский `I18nProvider` + cookie/localStorage — без reload.
- `html lang` обновляется провайдером (`suppressHydrationWarning` на `<html>`).

## Ручные / архитектурные правки

1. **Контракт ошибок:** API → код; UI → `t("errors.*")`.
2. **Уведомления:** ключ в `title` (без миграции Prisma `titleKey`).
3. **Канонические имена типов товаров в БД** остаются на RU; UI мапит через `labelProductType`.
4. **Имя канала Owner Direct в БД** русское; UI для `OWNER_DIRECT` показывает `t("nav.storesOwnerDirect")`.
5. **Единицы `мл`/`шт` в БД** — символы учёта; fallback UI через `units.*`.

## Как проверить вручную

1. Owner → переключатель RU ↔ TJ на каждой странице меню без F5.
2. Seller POS → то же.
3. Создать продажу / скидку / возврат / перемещение с ошибкой остатка — сообщение на языке UI.
4. Карточка магазина: вкладки продажи/запросы — статусы не `COMPLETED`/`PENDING`.
5. `npx tsc --noEmit`
